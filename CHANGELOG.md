# Changelog

All notable changes to this project are documented here.
The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [1.0.0] - 2026-10-23

### Added
- Radial "fan" overlay that appears under the cursor while dragging a file with a modifier key held.
- **Shift – Convert:** images (PNG, JPG, WEBP, BMP, ICO), video (MP4, MOV, WEBM, GIF, MP3), audio (MP3, M4A, WAV, FLAC, OGG).
- **Ctrl – Actions:** resize, compress, rotate, grayscale, strip metadata, mute, trim, extract frame, normalize, mono.
- **Alt – Tools:** copy path, ZIP, reveal in Explorer, open, send to Recycle Bin.
- Tray icon with help, output folder and log shortcuts.
- Inno Setup installer with optional start-with-Windows.
